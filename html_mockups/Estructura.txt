el stack sugerido es node.js, TS, express, postgre y prisma y el front con react y typescript.




Diseña una interfaz web completa, moderna, profesional y limpia para un **Sistema de Gestión de Inventario y Facturación**.

El sistema será utilizado principalmente desde computadoras en un negocio, por administradores, cajeros y encargados de inventario. La interfaz debe priorizar la claridad, rapidez de uso y facilidad para gestionar grandes cantidades de información.

## ESTILO GENERAL

* Diseño moderno, profesional y minimalista.
* Interfaz limpia y organizada.
* Utilizar un sidebar lateral fijo para la navegación principal.
* Usar tarjetas, tablas, gráficos, badges de estado, modales y formularios bien estructurados.
* Mantener una jerarquía visual clara.
* Evitar saturar las pantallas con demasiados elementos.
* Usar espacios adecuados entre componentes.
* Diseño responsive para computadora, tablet y móvil.
* Utilizar iconos claros y consistentes.
* Mantener el mismo sistema visual en todas las páginas.
* Los colores deben utilizarse principalmente para comunicar estados:

  * Verde: disponible / correcto.
  * Amarillo o naranja: stock bajo / advertencia.
  * Rojo: agotado / error.
  * Azul: información / acciones principales.
* Utilizar tipografía moderna y fácil de leer.

# ESTRUCTURA PRINCIPAL

El sistema debe tener un sidebar con las siguientes secciones:

1. Dashboard
2. Inventario
3. Facturación
4. Clientes
5. Proveedores
6. Reportes
7. Configuración

En la parte superior del sidebar mostrar el nombre y logo de la empresa.

En la parte superior de cada página mostrar:

* Título de la sección.
* Descripción breve.
* Breadcrumb cuando sea necesario.
* Usuario actualmente conectado.
* Notificaciones.
* Menú de perfil.

# EXPERIENCIA DE USUARIO

Priorizar especialmente:

1. Rapidez para realizar una venta.
2. Facilidad para encontrar productos.
3. Visibilidad del estado del inventario.
4. Alertas claras de stock.
5. Información importante visible desde el Dashboard.
6. Navegación sencilla.
7. Confirmaciones antes de acciones irreversibles.
8. Historial y auditoría para operaciones importantes.

El sistema debe sentirse como un **software empresarial real**, no como una colección de páginas CRUD.

Mantener una arquitectura visual consistente entre todas las secciones.

Crear primero la experiencia visual completa del sistema, incluyendo Dashboard, Inventario, Facturación, Clientes, Proveedores, Reportes y Configuración, manteniendo el mismo diseño, componentes y lenguaje visual en todas las pantallas.
